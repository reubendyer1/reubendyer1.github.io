About Me

I am an engineering student at Monash University with a strong interest in developing practical engineering solutions through mechanical design, electronics and software.

My project experience includes leading a student team in the development of a robotic system with over 50 custom-designed 3D-printed components, implementing real-time image processing on FPGA hardware, and developing machine learning-based autonomous navigation systems.

I enjoy combining theoretical engineering principles with hands-on design, prototyping and experimentation to solve challenging technical problems.

Embedded Systems | Digital Design

Real-Time FPGA Camera and Image Processing System

Developed a real-time video processing system using a DE10-Lite FPGA and an ESP32 camera module.

Implemented a three-processor Nios II architecture supporting camera acquisition, image processing and convolution-based edge detection.

Integrated SDRAM frame buffering, VGA display and RGB444 colour output, with selectable image filtering and display modes.

FPGA Verilog C Nios II SDRAM VGA

Robotics | Machine Learning

Autonomous Robot Navigation and Control System

Developed an autonomous navigation system for a Sphero robot capable of navigating complex maze environments.

Integrated a trained neural network navigation policy with classical robotics algorithms, including PID feedback control, Extended Kalman Filtering and A* path planning.

Implemented collision recovery and navigation safety mechanisms, with iterative testing in simulation and physical environments.
